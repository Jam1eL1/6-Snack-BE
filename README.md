<img width="1107" height="380" alt="Snack Project Banner" src="https://github.com/user-attachments/assets/1b33e7da-435f-47bd-bb99-1a0faf7e91b3" />

## 📑 Project Overview

**Snack** is a centralized SaaS solution designed to streamline office procurement. It allows businesses to integrate and manage purchase histories from fragmented online platforms (like Coupang, Naver Shopping, etc.) into a **single, unified dashboard.**

- **Centralized Management:** Consolidate snack items, quantities, and pricing data regardless of the vendor.
- **Bulk Operations:** Effortlessly register and manage large volumes of procurement data.
- **Data Insights:** Gain actionable insights through automated cost analysis reports, periodic statistics, and categorized spending breakdowns.
- **Efficiency:** Reduce manual administrative overhead, eliminate wasteful spending, and optimize corporate welfare operations.

  <summary><strong>View Directory Tree</strong></summary>
  
```text

├── repositories/   # Data Access Layer (Prisma)
├── routes/         # API Route definitions
├── middlewares/    # Auth, Error handling, Logging
├── dtos/           # Data Transfer Objects
├── cron/           # Scheduled tasks (Monthly budget automation)
├── config/         # Swagger & Environment config
└── lib/            # Shared library instances (Prisma client, etc.)
